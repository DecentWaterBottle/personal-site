A full-stack invoicing SaaS built as a portfolio project targeting freelancers. Multi-tenant from the ground up with proper row-level data isolation.

## Features

- JWT-based authentication
- Stripe payment integration

## Stack

Spring Boot 3 backend, React + TypeScript frontend, PostgreSQL, deployed on Railway.
