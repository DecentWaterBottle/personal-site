Loomina is a generative AI-based learning platform which gives the user complete freedom to choose whatever they want to learn about, and from whom they wish to learn it.
At Loomina I was responsible for the development of the backend API, utilizing Typescript with Koa and Supabase to create a scalable and efficient system. This included working with OpenAI's gpt-4o API and Prodia's image generation API. I also contributed to the frontend, utilizing Vue.js to implement several key features, such as live chat and OAuth 2.0 for Google login.

## Stack
Typescript, Koa, OAuth 2.0, Vue and Supabase DB and Authentication
